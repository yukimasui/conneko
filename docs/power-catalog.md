ブレーカー（漏電遮断器・ノーヒューズ遮断器・サーキットプロテクタ）、汎用のスイッチング電源（`generic.psu.dc24v`）、盤用換気ファンは既にあるので含めない。

## 共通の方針

### スイッチング電源（`din-psu.ts`）

- **容量で大きさが変わるシリーズを 1 機器にした**。容量は汎用のスイッチング電源と同じ params の `outputCurrent`（定格出力電流）で選び、
  `size`（幅・高さ）、銘板の W 数・電流、型式（`modelOf`。例: `S8VK-G06024`・`PS5R-VD24`）、入力電流（`loadCurrent`）が変わる。
- **端子 ID は `generic.psu.dc24v` とそろえた**（入力 `L`・`N`・`PE`、出力 `+V1`・`+V2`・`-V1`・`-V2`）。「DC24V 電源」のファミリーの中で機種を変えても電線はつながったまま。
  2 組目の出力は渡り配線用なので `optional`。同極の出力は `links` で内部導通。
- **出力は `supply`（DC24V、`limitCurrent` = 定格出力電流）**。受電している機器の消費電流の合計が容量を超えると `supply-overload`。
- **入力電流（AC100V 時 typ.）を `loadCurrent` にした**。上流のサーキットプロテクタの定格より大きいと `overload`（突入電流は見ていない）。
- 見た目は 1mm = 2px。S8VK-G は明るいグレーの樹脂ケースで下が入力・上が出力、PS5R-V は金属ケースに暗いグレーの正面で上が入力・下が出力。

### 制御用トランス

- **一次は受電端子（`input`）、二次は電源出力（`supply`、AC100V の `L`・`N`）**。一次と二次は内部でつながらない（絶縁トランス）。
  二次の 0 を `N`（接地側）、100 を `L`、110 タップを 110V の `L` にした。
- **二次側に `limitCurrent` を付けない**（トランスは過電流を制限しない）。二次側の負荷は CP などで保護しないと `no-protection` の警告が出る（テストあり）。
- 一次の電圧範囲: 0 は AC180〜240V、200 タップは AC180〜220V、220 タップは AC200〜240V（220 タップは使わないことがあるので `optional`）。
  AC100V をつなぐと `voltage-mismatch`。
- 混触防止板 E は `ground`。

### ヒューズホルダ・ノイズフィルタ・SPD

- **ヒューズホルダはサーキットプロテクタと同じ作り**（`line` → `load` の `directed`・`protects`、`protectionCurrent` = ヒューズの定格）。分類は `breaker`。
- **ノイズフィルタは LINE → LOAD を常時導通の `directed` の経路**にした（`protects` なし）。端子の `ratedCurrent` にフィルタの定格電流を書き、
  上流の保護電流がそれを超えると `terminal-overcurrent` の警告。
- **SPD は電路に並列に入る受電端子（`input`、消費電流なし）**。電圧の範囲を確かめ（三相 200V 系の SPD を AC100V につなぐと `voltage-mismatch`）、
  上流に保護機器（SPD の短絡故障に備えるブレーカー・ヒューズ）がなければ `no-protection` の警告が出る。PE を電路につなぐと `ground-fault`。

### 盤内設備

- 盤内照明は展開図で表示灯の記号（`schematic.elements` の `lamp`）にした。
- 盤用コンセントは L に `conductors: ['L']`、N(W) に `['N']` を書き、電圧側と接地側を逆につなぐと `conductor-mismatch`（テストあり）。
- 盤用ドアスイッチは c 接点（`cContact`）。展開図ではリミットスイッチ（`actuator: 'limit'`）の記号になる。
  照明を扉の開閉で点けるには NC（扉を開けると閉じる）を使う。

## 片側接地（機能接地）

国内の盤では、制御用トランスの二次の 0 や DC24V 電源の 0V を PE に接地する（片側接地）ことが多い。
一次側と絶縁された電源出力には `supply.isolated: true` を書き、チェック（`src/check/model.ts` の `classifySupplies`）で次のように扱う。

| つないだもの | 結果 |
|---|---|
| 絶縁された電源（`isolated`）の 1 つの導体（トランスの二次 0・DC 電源の 0V など）と PE | 指摘なし（info `one-side-ground`「片側接地」で知らせる） |
| 絶縁された電源の 2 つの導体をどちらも PE に（+V と 0V、二次の 0 と 100 など） | エラー `short-circuit`（接地を通した短絡） |
| 商用電源（R・S・T・L・N）・`isolated` を書いていない電源の導体と PE | エラー `ground-fault`（今までどおり） |
| 安全出力（OSSD）・テスト出力と PE | エラー `ground-fault`（今までどおり） |
| 別々の絶縁された電源の導体を同じ PE に（トランスの二次 0 と DC 電源の 0V） | 指摘なし（AC と DC の混触とはしない） |

- 片側接地したグループの接地端子（機器の PE・E）は地絡にしない。受電端子は、接地した電源の導体のどれかに合えばよい（極性・電圧の誤りは今までどおり見つかる）。
- 片側接地した導体（接地側）につながる受電端子は、上流の保護を求めない（電圧側の端子で `no-protection`・`overload` を確かめる）。
- 片側接地したグループの電線の色は、接地線の色（緑・緑/黄）と、その電源の回路の色（DC の青など）のどちらでもよい。接地端子・PE につながる電線は電線の太さを確かめない。
- 遮断器の下流の負荷（電流の余裕）は、片側接地した導体の先へはたどらない（接地を通してほかの電源の回路を数えないため）。
- `isolated` を書いた電源: 汎用のスイッチング電源（`generic.psu.dc24v`）、S8VK-G・PS5R-V、制御用トランスの二次、IAI PSA-24、三菱 R61P などの DC24V サービス電源、FX5U の DC24V サービス電源。
  商用電源（`generic.power-source.*`）、インバーター・サーボアンプの出力、機器の中の小さな電源出力（エンコーダ用 5V など）には書いていない。

## 推定・簡略化したこと

- **`omron.s8vk-g.dc24v`**: 入力が下・出力が上は S82K の代替資料で確かめたが、出力端子の数（+V・-V 各 2）と左右の並び（-V・-V・+V・+V）、
  入力端子の並び（L・N・PE）は推定。30W の入力電流は同じ容量の 5V 品（S8VK-G03005）の 0.6A、240W の AC100V 時の入力電流は AC115V 時 2.4A から 2.8A と推定した。
- **`idec.ps5r-v.dc24v`**: 入力が上・出力が下は取付説明（入力端子側を上）から判断した。出力端子の数・並び、入力端子の並び、60W 以外の高さ（95mm）は推定。
  入力電流はデータシートの表の値の並び（0.35 / 0.7 / 1.3 / 1.1 / 1.4 / 2.7A）を容量の順に割り当てた推定（90W 以上は力率改善付きで電流が下がる）。
- 汎用品（トランス・ヒューズホルダ・ノイズフィルタ・SPD・照明・コンセント・ドアスイッチ）は特定の型式の値ではなく、代表的な形と定格にした。
  トランス・照明は実物が大きいので縮小して描いた。
- メーカーのサイト（PDF）は自動では開けなかったため、検索結果に引用された製品ページ・データシートの内容と販売店の仕様表で値を確かめた。

## 機器定義では表せていないこと（コアへの提案）

1. **二次側・0V の片側接地**: トランスの二次 0（`N`）や DC 電源の -V を PE に接地すると、PE と電源出力がつながるため `ground-fault`（地絡）のエラーになっていた。
   → 対応済み。電源出力に `isolated: true`（一次側と絶縁された電源）を書き、その片側の導体の接地は片側接地（`one-side-ground`、info）として知らせるだけにした
   （下の「片側接地」）。
2. **ノイズフィルタの逆接続**: 向きのある経路（`directed`）は保護電流の伝わり方にだけ効き、電圧はどちら向きにも伝わる。
   LINE と LOAD を逆につなぐと下流の機器に「上流に保護機器がない」と出るだけで、逆接続そのものは指摘しない（テストで動作を確かめた）。
   提案: `directed` の経路で、電源が `to` の側からしか来ていないときに「逆につないでいないか」を指摘する（エアの `directed` と同じ考え方）。
3. **ヒューズの展開図の記号**: `protects` の経路は分類 `breaker` で遮断器の記号になる。ヒューズの記号（JIS C 0617 の長方形）を描き分けたい
   （`schematic` に `fuse: true` など）。
4. **トランスの容量**: AC の電源出力の容量（`limitCurrent` は保護電流として扱われる）を、保護とは別に負荷の合計と比べる仕組みがない
   （`supply-overload` は DC の + 側だけ）。トランスの二次の定格電流（容量 ÷ 100V）と負荷の合計を比べたい。
5. **突入電流**: スイッチング電源・トランスの投入時の突入電流と、ブレーカー・ヒューズの特性の組み合わせは確かめていない。
