# 汎用でよく使う制御機器の調査と実装状況

盤の内外でよく使う汎用の制御機器（リレー・押しボタン・セレクタスイッチ・表示灯・タイマー・ブザー・SSR・近接センサ・リミットスイッチ・電磁弁）について、
調査結果と Conneko での実装状況をまとめる（issue #11「汎用: 押しボタン・セレクタスイッチ・汎用リレー」）。
実在の代表的な型式に寄せ、端子番号・定格はメーカーの公開資料（2026-10 時点）で確かめた。資料で確かめられなかった点は「推定」と書いた。
三菱電機・IAI の機器は別の担当が扱うので、ここには含めない。

- 機器定義: `src/devices/catalog/` の下記のファイル（1 機器 1 ファイル）
- 共通部品: `src/devices/generic/`
  - `parts.ts` 描画部品（ネジ端子・文字・接点の図記号・ボタンやレンズの色）
  - `relay-socket.ts` DIN レール用ソケットに挿したリレー・タイマー（`buildRelaySocket`、c 接点の内部経路 `cContact`）
  - `omron-my.ts` オムロン MY2N / MY4N と H3Y、ソケット PYF08A-E / PYF14A-E の端子の並び
  - `panel-switch.ts` Φ22 の押しボタン・照光押しボタン・セレクタスイッチ（正面の操作部と背面の接点ブロック）
  - `omron-a22n.ts` オムロン A22N の型式・色・接点構成
  - `omron-e2e.ts` オムロン E2E NEXT（描画は `src/devices/keyence/sensor-parts.ts` の近接センサの部品を使う）
  - `smc-sy.ts` SMC SY シリーズの電磁弁
- 電気チェック・展開図の要素のテスト: `src/devices/generic-control.test.ts`

## 共通の方針

### リレー・タイマー（`relay-socket.ts`）

- **分類は `contactor`**。受電端子（コイル・タイマーの電源・SSR の入力）がちょうど 2 つなので、展開図では自動でコイルの記号になる。
- **ソケットに挿した状態で 1 機器**。部品表にはリレーとソケットが 1 行（型式は「MY2N DC24 + PYF08A-E」）で出る。
- **c 接点は COM → NC（`switch: 'NC'`）と COM → NO（`switch: 'NO'`）の 2 本**（`cContact`）。
- **DC コイルの極性**: MY2N / MY4N（LED 表示付き）の DC コイルは 14 が +、13 が −（カタログに「コイル極性をご確認の上、正しく配線してください」）。
  H3Y の DC 電源も 14(+)・13(−)。IDEC RU2S（標準の LED 付き）と RJ2S-CL は極性なし（極性があるのはダイオード付きの -D・-CD・-CLD 形）。
  極性のある端子は `conductors: ['+']` / `['-']` にしたので、逆につなぐと `conductor-mismatch`（テストあり）。
- **コイルの受電範囲**: 下限は動作電圧（MY・RU: 定格の 80%、RJ: 70%、H3Y: 85%）、上限は許容電圧（MY: 110%、RJ: 170%、H3Y: 110%）。
  RU2S の上限は資料で確かめられず 110% とした（推定）。
- **ソケットの端子の位置**: メーカーの上面図（Top View）のとおりに置き、電線の出る向きは「上の段は上、下の段は下、中の段は左右」にした。
  PYF14A-E は、2・3 段目の内側の端子（7・6、11・10）の電線が 1・4 段目の端子に重ならないよう、1 段目（3・2・1）と 4 段目（4・14・13）を
  半ピッチ横にずらして描いた（並び順は上面図のまま）。IDEC SJ2S-07L は上面図が横長なので、コイル端子（1・8）の側を下にして縦に描いた。
- **IDEC RJ の印字**: ソケットには通し番号と EN 番号の両方が印字されている（例: 6 (21)）。端子 ID は通し番号、印字（label）は「6(21)」。

### 押しボタン・セレクタスイッチ（`panel-switch.ts`・`omron-a22n.ts`）

- **左に正面の操作部、右に背面の接点ブロック**を描く（実機では接点ブロックは操作部の真後ろに 10mm 幅で並ぶ）。
  背面はメーカーの BOTTOM VIEW と同じ左右（オムロン A22N は裏から見て左からユニット位置 3・2・1）。
- **端子番号（A22N）**: 接点ブロックは位置によらず b 接点 1-2、a 接点 3-4。照光ユニットは中央（ユニット位置 2）で上が X1、下が X2。
  接点ブロックの色は実物どおり a 接点が青、b 接点が橙。
- **3 ノッチのセレクタ（G101）は 2 つの a 接点がどちらも 3-4 と印字**されるので、端子 ID にユニット位置を付けた（`P1-3`・`P1-4`・`P3-3`・`P3-4`。印字は 3・4）。
  データシートの接点動作表（Contact Configuration Table）どおり、位置 1 の a 接点が「1」（左）、位置 3 の a 接点が「2」（右）で閉じる。
- **2 ノッチのセレクタ（G100）**は位置 1 の a 接点が「2」（右）で閉じる。
- **照光・表示灯の LED は 24V AC/DC・極性なし**なので、`accepts` を DC と AC の両方（21.6〜26.4V、導体の指定なし）にした。
  照光押しボタンの LED は使わないこともあるので `optional`、表示灯の LED は未接続を警告する。
- 展開図の操作の種類は、押しボタンを `pushbutton`、リミットスイッチを `limit` にした。セレクタの記号はまだないので省略（普通の接点になる）。

### センサー・電磁弁

- **E2E NEXT**: 茶 = +V（DC10〜30V）、黒 = 出力（NO）、青 = 0V。NPN は出力 → 0V、PNP は出力 → +V への `switch: 'output'`（200mA）。
  B1D（PNP）は IO-Link COM2 対応品だが、IO-Link マスタにつながないときは普通の PNP 出力（SIO モード）として動くので、そのように表した。
- **WLCA2-2**: 旧来の WL シリーズの端子番号（b 接点 1-2、a 接点 3-4）。新しい WL-N シリーズ（WLCA2-2-N）は 11-12・13-14 なので別の機器になる（未定義）。
- **SY3120 / SY3220（L 形プラグ・Z）**: リード線は赤が +、黒が −（極性あり）。端子 ID はシングルが `+`・`-`、ダブルが `A+`・`A-`・`B+`・`B-`。
  消費電力 0.4W（表示灯込み）なので負荷電流は 17mA とした。コイルは `schematic.elements` で展開図のコイルにした。

## 推定・簡略化したこと

- **`omron.wlca2-2`**: スイッチボックスの中の端子 1〜4 の位置（左の列に 1・2、右の列に 3・4）は推定（データシートは端子番号と接点形式だけ）。
- **`idec.ru2s-d24`**: コイル電圧の上限（110%）は推定。ソケット SM2S-05 の端子の位置は端子配置図（小さい図）からの読み取り。
- **`idec.ru4s-d24`**: ソケット SY4S-05 の外形と端子の位置（上 2 段に 8〜5・4〜1、リレーの下に 14・13、最下段に 12〜9）は推定。
  IDEC の公式資料を開けなかったため、コイル電流・接点定格は販売店の仕様表（複数）で確かめた。コイル電圧の上限は RU2S と同じく 110%（推定）。
- **`idec.hw1z-2pq4b`**: 裏の端子 X1・X2 の位置（上 X1・下 X2）は推定。データシート本体（PDF）は自動では開けず、その内容を引用した検索結果と販売店の仕様表で値を確かめた。
- **外形**: リレー・ソケット・SSR は外形図の寸法（1mm ≒ 2px）、Φ22 の操作スイッチは 1mm ≒ 1.5px。リレーのカバーの中の接点・コイル、ボタンの陰影は見た目のための描画。
- **MY の接点定格**: 国内カタログの表記（MY2: AC220V 5A / DC24V 5A、MY4: 3A、抵抗負荷）を説明に書いた。
- **LED・コイルの電流**: A22N の LED は色で 12mA（赤・橙・黄・青）/ 5mA（白・緑）と変わるが、`loadCurrent` はパラメーターで変えられないため 12mA にした。
  MY2N AC100V のコイル電流は 50Hz / 110V の 12.9mA にした。

## 未実装と理由

- **IDEC YW シリーズ（押しボタン・セレクタ・表示灯）**: 接点ブロックの位置（1・2・3）と a/b 接点の構成、LED の電流（13〜14mA）は確かめたが、
  **接点ブロックの端子の印字（番号）が公開資料で見つからなかった**ため見送った。端子 ID を実機の印字に合わせられないので、同じ Φ22 の代表品としてオムロン A22N を作った。
- **H3Y の AC 電源品（AC100〜120V）・H3Y-4（4c）**: H3Y-4 は PYF14A-E に挿す 4c 品で、`buildRelaySocket` の PYF14A-E の配置で作れる。今回は DC24V の 2c だけにした。
- **IDEC RU の AC コイル品**: AC100V の型式（A100）の定格を確かめられなかった（RU4S-D24 は v0.6.21 で追加）。
- **WL-N シリーズ（WLCA2-2-N）**: 端子番号が違う（11-12・13-14）別機種。必要なら `omron-wlca2-2.ts` の端子 ID を変えて追加できる。
- **DIN 端子箱形の電磁弁（SY の D・Y 形）**: 端子 1・2・接地で無極性。今回は L 形プラグだけにした。

## 機器定義では表せていないこと（コアへの提案）

1. **c 接点の展開図の切り出し**: `src/schematic/elements.ts` は経路ごとに接点を切り出し、使った端子を除いていくため、COM を共有する
   c 接点では **COM → NC の b 接点だけが記号になり、NO 側の端子（MY2N の 5・8 など）は「箱」に入る**（電気チェックは正しく動く）。
   提案: COM を共有する NC・NO の組を c 接点（切換接点）の記号 1 つに切り出す（`contact-co`）か、COM を複数の要素で共有できるようにする。
2. **限時接点（タイマー）**: H3Y の限時接点は普通の a 接点・b 接点として表した。チェックでは「動作中」に閉じる接点として扱われるので配線の誤りは見つかるが、
   展開図ではタイマーの記号（オンディレーの限時 a 接点・b 接点）にならない。
   提案: `InternalLink` に `timed?: 'on-delay' | 'off-delay'` を足し、展開図の記号を描き分ける。
3. **セレクタスイッチの位置**: 接点が閉じる位置（左・中・右）を書けない。3 ノッチの 2 つの a 接点は実際には同時に閉じないが、
   短絡のチェックの「機器を 1 台ずつ動作させた状態」では両方が同時に閉じたとみなされる。また展開図のセレクタの記号がない。
   提案: `InternalLink` に `positions?: string[]`（その接点が閉じる位置）、`ContactActuator` に `selector` を足し、位置ごとの状態で短絡を調べる。
4. **SSR の出力は交流専用**: G3NA の出力（1-2）に直流の負荷をつないでも警告できない（接点の経路は電圧の種類を問わずに通すため）。
   接点・出力の定格（電圧・電流）を負荷と比べる仕組みもない（`docs/known-limitations.md` の「リレー接点の定格は確かめていない」と同じ）。
   提案: `InternalLink` に `rating?: { system: 'AC' | 'DC'; maxVoltage; current }[]` を足し、経路を通る電源と負荷電流を比べる。
5. **ブザーの展開図の記号**: `schematic.elements` の種類に `buzzer` がないため、ブザーは端子を並べた「箱」になる。提案: `buzzer` を足す。
6. **パラメーターで変わる消費電流**: LED の色で電流が変わる（A22N・M22N）、コイル電圧で電流が変わる（MY）。`loadCurrent` を `ParamDependent` にできれば、
   コイル電圧を別の機器に分けなくて済む（IAI の調査の提案 1 と同じ）。
