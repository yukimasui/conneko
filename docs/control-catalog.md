# 表示・操作機器と盤内の制御補助機器の調査と実装一覧

生産設備でよく使うのに、これまで Conneko に無かった表示・操作機器（積層信号灯・押しボタン・表示灯・フットスイッチ）と、
盤内の制御補助機器（タイマー・温度調節器と温度センサ）を調べ、`src/devices/catalog/` に機器定義として実装した。
実在の代表的な型式に寄せ、端子番号・定格はメーカーの公開資料（2026-10 時点。メーカーのサイトに届かないものは販売店・代理店が掲載した資料の写しや、
資料の内容を検索で確かめたもの）で確かめた。資料で確かめられなかった値は機器定義の `estimated` と、下の表の行に「推定」と書いた。

- 機器定義: `src/devices/catalog/` の下記のファイル（1 機器 1 ファイル）
- 共通部品: `src/devices/generic/`
  - `patlite-lr.ts` パトライト 積層信号灯 LR6 / LR4（段数・色・ブザーで端子と大きさが変わる）
  - `omron-h3cr.ts` オムロン H3CR-A8 ＋ ソケット P2CF-08
  - `omron-e5cc.ts` オムロン E5CC（正面と背面の端子台）
  - `temp-sensor.ts` シース熱電対・シース測温抵抗体（リード線の先端が端子）
  - `fuji-ar22.ts` 富士電機 AR22 / DR22（描画は `panel-switch.ts`。接点ブロックの色を富士電機の色にするため `unitColors` を足した）
- 電気チェック・展開図・ファミリーのテスト: `src/devices/control-catalog.test.ts`

## 方針

### 積層信号灯（`patlite-lr.ts`）

- **段数と色は 1 つのパラメータ**（`colors`。型式の末尾の色記号そのもの。先頭が最上段）。段数でリード線（端子）の数と機器の高さが変わる（`size` と `terminals` を関数にした）。
  端子 ID は `COM`・`L1`〜`L5`（段の番号。上から）・`BZ`。段数を減らすと、なくなった段の電線は外れる。
- **電気的には各段のリード線とコモンが受電端子**（`input`、DC21.6〜26.4V、極性なし）。PLC のトランジスタ出力（NPN ならコモンを +24V、PNP ならコモンを 0V）、
  リレー接点のどちらで駆動してもチェックが通る。消費電流は段数とブザーから求める（`loadCurrent` を関数にした）。
- **展開図では端子を並べた箱**になる。段ごとの表示灯の記号にすると、共通のコモンが複数の記号に入り、展開図の「端子は 1 つの要素にだけ入る」決まり
  （`src/schematic/elements.test.ts`）に合わないため。

### タイマー（`omron-h3cr.ts`・`omron-h3dt-n2.ts`）

- 既存の H3Y と同じく **分類は `contactor`**。H3CR-A8 は受電端子がちょうど 2 つ（2・7）なので展開図で自動でコイルになる。
  H3DT-N2 はスタート入力 B1 も受電端子なので、`schematic.elements` で A1-A2 をコイルに指定した。
- **限時接点は `timed: 'on-delay'`**（展開図で限時動作の記号）。どちらもマルチモードだが、図面ではオンディレーとして表す。H3DT-N2 の R2 は params の `r2` で瞬時接点にできる。
- H3CR-A8 の DC 電源は極性あり（7 が +、2 が −）なので、DC の受電条件にだけ `conductors` を付けた（AC は極性なし）。逆につなぐと `conductor-mismatch`（テストあり）。
- P2CF-08 の端子は上の段 左から 6・5・4・3、下の段 左から 7・8・1・2（上面図のとおり）。

### 温度調節器と温度センサ（`omron-e5cc.ts`・`temp-sensor.ts`）

- 端子の記号はマニュアル H174 の A〜R を、現行品の端子番号 1〜18（A〜F = 1〜6、G〜L = 7〜12、M〜R = 13〜18）として読んだ。オプションなし（-800）なので 13〜18 と 3 は灰色で描き、端子にしない。
- **リレーの制御出力・補助出力は a 接点**（`switch: 'NO'`、`ratedCurrent: 3`）。ヒーター用の電磁接触器のコイルなどを開閉する。
- **電圧出力（QX）の制御出力 1(+)・2(−) は電源の出力**（`supply`、DC12V、`limitCurrent: 0.021`）として書いた。SSR（`omron.g3na-210b`）の入力 3(+)・4(−) へ直接つなぐとチェックが通り、
  逆につなぐと極性のエラーになる（テストあり）。実機では温度に応じて ON/OFF する出力だが、図面では常に電圧の出る端子として扱う。
- センサ入力（4・5・6）と熱電対・測温抵抗体のリード線は `signal`（信号の種類はなし）。熱電対と測温抵抗体の取り違えはチェックしない。

### 押しボタン・表示灯（富士電機 AR22・DR22）

- オムロン A22N と同じ `panel-switch.ts` で作り、名前を「押しボタンスイッチ」「照光押しボタンスイッチ」「表示灯」にしたので、既存のファミリーにメーカー違いとして入る。
- 接点ブロックの色（a 接点 = 青、b 接点 = 赤）はカタログで確かめた。端子番号と並びは確かめられず推定（オムロン A22N と同じく b 接点 1-2、a 接点 3-4 とした）。

## ファミリー（`src/devices/families.ts` に足したルール）

- `signal-tower` 積層信号灯（観点: 大きさ Φ60 / Φ40）、`foot-switch` フットスイッチ、`temp-controller` 温度調節器（観点: 制御出力）、`temp-sensor` 温度センサ（熱電対・測温抵抗体）
- 既存の `timer` に観点「取付け」（ソケット / DIN レール）を足し、既定の機種を今までどおり H3Y にした。

## 実装しなかったもの・確かめられなかったこと

- **オムロン 電子カウンタ H7CX**・**デジタルパネルメータ K3HB**: 端子配列（11 ピン・ねじ端子の番号と CP1・CP2・リセット・出力の対応）を資料で確かめられなかったため、今回は実装しなかった。
- PATLITE LR のリード線の色・点滅を選ぶ線、富士電機 AR22 の接点ブロックの端子番号と接点の定格、H3DT の端子の位置は、メーカーの資料（取扱説明書・カタログの PDF）に届かず確かめられなかった（上の表の「推定」）。
