# まだ表せないこと・チェックしていないこと

機器定義の型と配線チェックで、現時点では表せない（または確かめていない）点の一覧。
KEYENCE・三菱電機 PLC・安全機器の担当がまとめた拡張提案のうち、取り込み済みのものは
`docs/device-authoring.md` に記載し、残りをここに残している。

## 接点・出力

- 短絡の検査は「通常時」と「機器を 1 台ずつ動作させた状態」だけで行う。2 台以上が同時に動作したときだけ起きる短絡は見つけない
  （インタロックのある正逆転回路を誤検出しないため）。
- 接点（a/b 接点）の定格電流は v0.6.19 から確かめる（`contact-overload`）。定格を書いたのは三菱電機の電磁接触器の主接点、
  オムロン MY・IDEC RU/RJ のリレー、フォースガイドリレー（G7SA・RF1V）、インバーターの異常出力だけ。負荷の種類（誘導負荷・ランプ）による定格の違いは見ない。
  電源の来ていない側を決められない接点（両側に電源・両側に負荷）は確かめない。

## 信号

- 2線式センサーの漏れ電流・残留電圧と入力の OFF 電流・最小 ON 電圧は v0.6.19 から書ける（`two-wire-input`）。データを入れたのは
  KEYENCE EV・SMC D-M9B（漏れ電流・残留電圧）と KV-C64XC（最小 ON 電圧、2 線式不可）だけ。ほかの入力ユニットの OFF 電流は未記入。
- アナログの帰り道（入力の −側が出力の機器の GND とつながっているか）は v0.6.20 から確かめる（`analog-return`）。
  基準の端子（`signal.ref`）を書いたのは KV-AM40V・KV-TP40・FR-E820・IL-1000 だけ。電源の 0V を基準にするセンサー（GP-M・FD-Q・LR-W のアナログ出力）は
  基準を書いていないので、入力の −側が未配線のときだけ指摘する。

## 装着（バス）と内部電源

- 親（CPU）の外部電源端子の電流に装着したユニットの消費電流を足すのは、`bus.feeds` を書いた KEYENCE の KV-8000・KV-X・KV-EC01 だけ（v0.6.16）。
  iQ-R・FX5 の電源ユニット・CPU は AC 入力なので、内部電源の消費から入力電流を求めない。
- 電源の容量のチェック（`supply-overload`、v0.6.16）は DC の + 側の電源出力だけ。接点・出力はすべて閉じたとみなして合計するので、
  同時に動かない負荷があると多めに数える。消費電流（`loadCurrent`）を書いていない機器は数えない。
- iQ-R の空きスロットの占有点数を PLC パラメータで変えた場合（0 点など）は表せない（初期設定の 16 点として数える）。
- KV-8000 / KV-X の自動割付け（R000 から 16 点単位、出力は入力の次のチャネル）は公開資料で確認できておらず、実機の挙動からの推定。
  増設ユニット KV-EB1 による拡張（48 台）は表していない。

## コネクタ・変換ケーブル

- 変換ケーブルのピンの対応は、`src/data/cables.ts` に書いたもの（FCN40 ⇔ MIL40 のミスミ PTHAS-F40-M40・東洋技研 KB40N-4F1H）だけ選べる（v0.6.12）。
  ほかの製品・ほかのコネクタの組み合わせは、同じ番号どうしとして扱う。
- 電線の端末処理と、端子が受け入れる電線（方式・太さ・定格電流）は v0.6.13 から書ける。データを入れたのは東洋技研のコネクタ端子台・レール用端子台だけ
  （ほかの機器は書いていないので確かめない）。被覆の外径・むき長さは確かめない。

## 機器の定義

- 外形（幅・高さ）は `size`、負荷電流・内部電源の消費電流などの数値は `NumOrParam` の関数でパラメータから求められる（v0.6.8）。
  ただし既存の機器の多くは、まだ代表の値か別の機器のまま（SCON-CB の 400〜750W 用の幅、XSEL の 5〜8 軸、東洋技研のレール用端子台の極数など）。

## 安全回路

- 安全機能全体の PL の計算（入力・論理・出力の組み合わせ、MTTFd・DC・CCF）は行わない。図面の要求 PL を下回る機器を個別に警告するだけ。
- B10d はデータシートに記載が見つからない機器が多く、ほとんど未記入。
- 1 つの端子の機能が配線で変わる場合（G9SE の T32 / T33 は手動・自動リセットのどちらにも使う）は、押しボタンの有無で判定している。
- 安全コントローラーの汎用安全入力（`configurable`）は、プログラムの設定を読めないため、片側だけの配線などを注意（info）にとどめる。
