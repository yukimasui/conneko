# センサー（KEYENCE 以外のメーカー・汎用品）の調査と実装状況

生産設備でよく使うのに今までなかったセンサーのうち、KEYENCE 以外のメーカー（オムロン・パナソニック・SMC）と汎用品について、
調査結果と Conneko での実装状況をまとめる。熱電対・測温抵抗体・温度調節器は別の担当が扱うので、ここには含めない。
定格・線色・ピンの割付けはメーカーの公開資料（2026-10 時点。製品ページ・データシート・販売店の型式表）で確かめた。
メーカーのサイトの PDF を直接は読めなかったものがあり、検索で確かめられなかった値は「推定」と書き、機器定義の `estimated` にも書いた。

- 機器定義: `src/devices/catalog/` の下記のファイル（1 機器 1 ファイル）
- 共通部品: `src/devices/sensor/`
  - `parts.ts` 縞の芯線（エンコーダのラインドライバの「黒/赤」など）を描くケーブル `colorCable`、KEYENCE 用の組み立てで作った機器のメーカーの差し替え `withMaker`
  - `omron-e3z.ts` オムロン E3Z（本体の絵・型式の組み立て）
  - `panasonic-cx400.ts` パナソニック CX-400
  - `omron-e6b2.ts` オムロン E6B2-C
  - 芯線・M8 / M12 コネクタ・近接センサの本体の描画は、KEYENCE のセンサーと同じ部品（`src/devices/keyence/sensor-parts.ts`、`photo.ts`）を使う
- テスト: `src/devices/sensor/sensor.test.ts`（出力の内部経路、コネクタとセンサーケーブルの相性、型式、KV の入力ユニットへつないだときの NPN / PNP・ラインドライバ・アナログのチェック）

## 共通の方針

- **一般名称とファミリー**: 既存のファミリーに入るよう、光電センサは `光電センサ（反射型）` / `光電センサ（透過型 投光器）` / `光電センサ（透過型 受光器）`、
  近接センサは `近接センサ（DC3線式）`、流量スイッチは `流量センサ（…）` にした。ロータリエンコーダ（`ロータリエンコーダ（インクリメンタル）`）と
  フロートスイッチ（`フロートスイッチ`）は一般名称ごとのファミリーになる（`families.ts` のルールは足していない）。
- **端子 ID**: ケーブルの芯線は色略号（BN 茶・BU 青・BK 黒・WH 白・OG 橙・SH シールド）、縞の芯線は色略号をつなげる（BKRD = 黒/赤）。
  コネクタは `CN`、ピンは `CN#1`〜`CN#4`（1 茶・2 白・3 青・4 黒。センサーケーブル `generic.m8-4p-cable` / `generic.m12-4p-cable` とつながる）。
- **出力と信号の種類**: NPN / PNP の出力線は `signal: { dir: 'out', kind: 'npn' | 'pnp' }` と内部経路 `switch: 'output'`（NPN は → 0V、PNP は → +V）。
  PLC の入力のコモンの極性と合わないと `signal-polarity` のエラーになる。エンコーダのラインドライバ出力は `line-driver`（DC 入力につなぐと `signal-kind` の注意）、
  PF3W7 のアナログ出力は `analog-v` / `analog-i`（基準は青 0V）、フロートスイッチは無電圧接点 `contact`。
- **電源の範囲**: E3Z・CX-400 の「DC12〜24V ±10%」は 10.8〜26.4V、E6B2-CWZ1X は 4.75〜5.25V（24V をつなぐと `voltage-mismatch`）。
- **型式**: パラメータで決まる型式は `modelOf` で組み立てる（E3Z は NPN の 6 が PNP で 8、コネクタ品は D61 → D66・D62 → D67。CX-400・GX は PNP で末尾に -P）。
- **透過型**: 投光器と受光器を別々の機器にし、それぞれ電源をつなぐ（KEYENCE の PZ-G と同じ）。組の型式は説明に書いた。

## 確かめられなかったこと・対象外

- 推定の行のとおり（CX-422・CX-491 の消費電流、PNP の E2E-X□B1D□-M1 のピン 2、E6B2-C のシールドの芯線の扱い、PF3W7 の線色ほか、フロートスイッチの定格）。
- CX-400 の M8 コネクタ品（-Z）、距離設定型 CX-44□（桃の切換線あり）、E3Z の PNP 投光器・受光器を単品で注文するときの型式、
  E6B2-C の PNP オープンコレクタ（CWZ5B）・電圧出力（CWZ3E）、パナソニック EX-10 / EX-20、オムロン リミットスイッチ D4C / ZC は未実装。
- 水の配管（PF3W7 の IN / OUT）は端子にしていない（エアのチェックの対象外）。
