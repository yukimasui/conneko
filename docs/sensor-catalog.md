## 共通の方針

- **一般名称とファミリー**: 既存のファミリーに入るよう、光電センサは `光電センサ（反射型）` / `光電センサ（透過型 投光器）` / `光電センサ（透過型 受光器）`、
  近接センサは `近接センサ（DC3線式）`、流量スイッチは `流量センサ（…）` にした。ロータリエンコーダ（`ロータリエンコーダ（インクリメンタル）`）と
  フロートスイッチ（`フロートスイッチ`）は一般名称ごとのファミリーになる（`families.ts` のルールは足していない）。
- **端子 ID**: ケーブルの芯線は色略号（BN 茶・BU 青・BK 黒・WH 白・OG 橙・SH シールド）、縞の芯線は色略号をつなげる（BKRD = 黒/赤）。
  コネクタは `CN`、ピンは `CN#1`〜`CN#4`（1 茶・2 白・3 青・4 黒。センサーケーブル `generic.m8-4p-cable` / `generic.m12-4p-cable` とつながる）。
- **出力と信号の種類**: NPN / PNP の出力線は `signal: { dir: 'out', kind: 'npn' | 'pnp' }` と内部経路 `switch: 'output'`（NPN は → 0V、PNP は → +V）。
  PLC の入力のコモンの極性と合わないと `signal-polarity` のエラーになる。エンコーダのラインドライバ出力は `line-driver`（DC 入力につなぐと `signal-kind` の注意）、
  PF3W7 のアナログ出力は `analog-v` / `analog-i`（基準は青 0V）、フロートスイッチは無電圧接点 `contact`。
- **電源の範囲**: E3Z・CX-400 の「DC12〜24V ±10%」は 10.8〜26.4V、E6B2-CWZ1X は 4.75〜5.25V（24V をつなぐと `voltage-mismatch`）。
- **型式**: パラメータで決まる型式は `modelOf` で組み立てる（E3Z は NPN の 6 が PNP で 8、コネクタ品は D61 → D66・D62 → D67。CX-400・GX は PNP で末尾に -P）。
- **透過型**: 投光器と受光器を別々の機器にし、それぞれ電源をつなぐ（KEYENCE の PZ-G と同じ）。組の型式は説明に書いた。

### 方針・チェックとのつながり

- **一般名称とファミリー**: 既存のファミリーに入る名前にした（`families.ts` は変えていない）。EX は `光電センサ（透過型 投光器）` など、EE-SX67 は `光電センサ（フォトマイクロセンサ 溝形）`（光電センサの「検出方式」で分かれる）、
  D4C・ZC は `リミットスイッチ`、E2E の 2 線式は `近接センサ（DC2線式）`。E6B2 は 4 つの出力形式が同じ `ロータリエンコーダ（インクリメンタル）` に入り、端子 ID（BN・BK・WH・OG・BU・SH）がそろっているので「機種を変える」で配線が保たれる。
- **出力と PLC 入力**: EX・EE-SX67 の NPN、E6B2-CWZ5B の PNP は、KV の入力のコモンの極性と合わないと `signal-polarity` のエラー。
  EX の出力は 50mA（E3Z・CX-400 の 100mA より小さい）で、出力の内部経路の `ratedCurrent` に書いた。
- **2 線式**: E2E の DC 2 線式は茶・青の 2 本とも `2wire`。片方を入力点、もう片方を入力のコモンと反対の極へつなぐ。漏れ電流 0.8mA・残留電圧 3V を書いたので、
  2 線式を使えない入力（KV-C64XC）につなぐと `two-wire-input`、入力の OFF 電流・最小 ON 電圧が分かる入力（NX1P2: OFF 1mA・ON 15V）では照合する（どちらも満たすので注意は出ない）。
- **リミットスイッチ**: D4C・ZC の b 接点は直接開路動作ではないので、セーフティリレーの安全入力に入れると `not-direct-opening` の注意、a 接点なら `estop-not-nc`。安全回路には D4N などの安全リミットスイッチを使う。

### 確かめられなかったこと・対象外

- 推定の行のとおり（EX-10 の残留電圧、EX-26A の消費電流、D4C の線色、ZC の端子の並び、E6B2-CWZ5B / CWZ3E の消費電流、EE-SX67 の消費電流、E2E-X3D1-N の型式）。
- EX-10 / EX-20 の EX-11A（前面検出）・EX-13・EX-22・EX-24・EX-29、PNP の EE-SX67□P、ZC のローラ・レバー形、D4C の表示灯付き・コネクタ形は未実装。

### 方針・チェックとのつながり

- **ロードセルの信号**: ブリッジの出力（mV）に当てはまる信号の種類（`signal.kind`）がないので、緑・青と指示計の SIG± には種類を書いていない（PLC のアナログ入力へ直接つないでも指摘しない）。
  電源側は、指示計の EXC± を電源（`supply`、DC10V・230mA）、ロードセルの赤・白を受電（`input`、DC2.5〜15V）にしたので、DC24V につなぐ誤りと、つなぎすぎ（350Ω 相当で 9 台）の `supply-overload` が分かる。
  4 線式は指示計の EXC+ と SEN+、EXC− と SEN− を電線で短絡する（SEN± は `signal` なので、短絡を忘れても指摘しない）。
- **指示計の出力**: 制御出力は NPN として PLC の入力のコモンの極性を照合する（マイナスコモンにつなぐと `signal-polarity`）。アナログ出力（4〜20mA）は `analog-i` で、インバーターの電圧入力（端子 2）につなぐと `signal-kind` の注意。
- **一般名称とファミリー**: ロードセル（`ロードセル（シングルポイント）`）・ウェイングインジケータ・フロートなしスイッチ・電極保持器・`ロータリエンコーダ（アブソリュート）` は、一般名称ごとのファミリーになる（`families.ts` のルールは足していない）。W12 は `光電センサ（反射型）` に入る。
- **61F-G の電極**: 液を通して電極の間が導通することは内部経路にしていない（電極の配線は `signal`）。出力の 1c 接点は無電圧接点（`contact`）として PLC の入力にもつなげる。
