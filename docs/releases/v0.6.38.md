## 改善（チェック）: 片側接地をエラーにしない

- トランスの二次の 0 や、DC24V 電源の 0V（-V）を接地（PE）につなぐ片側接地（機能接地）を、地絡のエラーにしないようにしました（チェック結果に「片側接地」と info で出ます）。
  - 一次側と絶縁された電源（スイッチング電源・制御トランスの二次・PLC のサービス電源など）の出力に `isolated` を付けて見分けます。
  - 同じ電源の両方の導体（+ と -、0 と 100）を接地すると短絡、商用電源（R・S・T・L・N）や安全出力を接地すると、今までどおり地絡のエラーです。
  - 片側接地したところでは、接地線の色・太さ、接地側の導体の保護を求めないようにしました。
