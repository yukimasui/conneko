## 主な変更

### リンクを縦向きにできるようにしました（#36）
- リンク（電線・ネットワーク・エア）を縦向きにできます。縦のリンクは上下で電線をつなぐ細い形で、PLC の I/O のように上下に端子が並ぶ機器の下へ、横に詰めて並べられます。
- 切り替えは、概念図で **V キー**（選んだリンクをまとめて）、リンクの右クリック「縦向きにする / 横向きにする」、プロパティの「向き」から。展開図の「縦にする」と同じキーです。
- 機器の右クリック「**上下の端子のリンクを縦にしてそろえる**」で、端子につないだリンクを端子の並び順のまま一列に並べます。端子の真下に置けないぶんは電線を横に振り、電線が交差しないようにします（「横にしてそろえる」で元の形に戻せます）。
- 縦のリンクの相手のシートの一覧は、矢印の先に縦書きで出します（画面・印刷・SVG）。
- JSON では `params.orientation: "vertical"`、または `params.side` に `"top"` / `"bottom"` を書くと縦のリンクになります。
