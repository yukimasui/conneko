# リリースノート

main にマージされると、GitHub Actions（`.github/workflows/release.yml`）がリリースを作る。

## リリースの手順

1. PR の中で `package.json`・`package-lock.json` の `version` を上げる（例: 0.6.1 → 0.6.2）
2. 同じ PR に、このフォルダへ `v<バージョン>.md`（例: `v0.6.2.md`）を書く。リリースの本文になる
3. PR を main にマージする

マージすると、ワークフローが次を行う。

- タグ `v<バージョン>` がまだなければ、テスト・ビルドをして、`conneko-v<バージョン>.html` を添付したリリースとタグを作る
- タグがすでにあれば何もしない（バージョンを上げていないマージではリリースしない）
- `v<バージョン>.md` がなければ、GitHub が PR の一覧からリリースノートを作る

テストかビルドが失敗したときはリリースを作らない。直して main にマージし直すか、Actions の画面から「リリース」を手動で実行し直す。
