## 配線言語に入力候補（インテリセンス）

「配線言語」のエディタで、書いている位置に書けるものの候補が出るようになりました。機器種別や端子 ID を覚えていなくても書けます。

- 行頭で `ELB` と打つと「`ELB2 =`（新しい機器を宣言）」が出て、選ぶと続けて機器種別の候補が出ます。
  機器名の接頭辞が合う機種（漏電遮断器など）が先に並び、`漏電`・`NV32`・`三菱 漏電` のように名前・型式・メーカーでも探せます。
- 機器種別の `(` の中ではパラメータ名、`ratedCurrent=` の後では選べる値が出ます。
- `ELB1.` と打つと、その機器の端子が、役割・呼び名・つながっているかつきで出ます。`-- ` の後では宣言した機器が出て、選ぶと続けて端子が出ます。
- 電線の後ろでは、色・太さ（許容電流つき）・電線の種類・端末処理などが出ます。
- 候補は Ctrl+Space でいつでも出せます（Mac は ⌥+` か ⌥+I でも）。Enter で選び、Esc で閉じます。

あわせて、エディタを作り直しました。

- 機器名・機器種別・線番・リンクなどを色分けして表示します。
- 誤りのある箇所に波線を引き、行番号の横に印を付けます（マウスを乗せると内容が出ます）。
- Ctrl+Z / Ctrl+Y はエディタの中の取り消し・やり直しです。
