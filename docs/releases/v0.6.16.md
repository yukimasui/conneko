- KEYENCE KV-8000・KV-X の CPU、KV-EC01 に装着した拡張ユニットの消費電流を、CPU（カプラ）の電源端子の電流に加えて、上流のサーキットプロテクタなどの定格と比べるようにしました。
- 電源の容量のチェックを追加しました。電源ユニットなどの DC24V 出力から受電している機器の消費電流の合計が、容量（定格出力電流）を超えると注意を出します（`supply-overload`）。
- 三菱電機 FX5U の DC24V サービス電源（400mA）は、増設ユニットへ供給する DC24V と容量を分け合うものとして、両方を合わせて確かめます。
- KV-XH04ML のように、入出力ではなくリレーを占有するユニットを「占有」として表示するようにしました（今までは入力として表示していました）。
- KV-EC01 に装着したユニットは、先頭番号を手で指定できるようにしました（番号は EtherCAT の PDO 割付で決まるため）。後ろのユニットは指定した番号の続きから数えます。
