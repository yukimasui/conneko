# 空圧・真空機器（CKD・コガネイと SMC の追加分）の調査と実装状況

生産設備でよく使うのに今までなかった空圧・真空機器（GitHub issue #78）のうち、CKD・コガネイの電磁弁・シリンダ・スピードコントローラと、
SMC の電空レギュレータ・2 ポート電磁弁・真空ユニット・スライドテーブル・ロッドレスシリンダについて、調査結果と Conneko での実装状況をまとめる。
SMC の SY・シリンダ・3 点セットなど既存の機器は [generic-catalog.md](generic-catalog.md) と [device-authoring.md](device-authoring.md) を参照。

定格・ポート・型式はメーカーの公開資料（2026-11 時点。カタログ PDF・製品ページ・販売店の型式表）を検索で確かめた。
この環境からはメーカーのサイトの PDF を直接読めなかったため、検索結果の要約で確かめられなかった値は「推定」と書き、機器定義の `estimated` にも書いた
（`src/devices/estimates.test.ts` が一致を検査する）。外形寸法・本体の色などの見た目は、写真・外形図の記憶にもとづく近似。

- 機器定義: `src/devices/catalog/` の下記のファイル（1 機器 1 ファイル）
- 共通部品:
  - `src/devices/air/body-valve.ts` ボディ配管形の 5 ポート電磁弁（CKD 4GA1・コガネイ F10。端子 ID は SMC SY と同じ +・−・A+・B+ と A・B・P・EA・EB）
  - `src/devices/ckd/` CKD の電磁弁 4GA1 とマニホールド M4GA1（`valve.ts`）、シリンダの型式・ロゴ（`cylinder.ts`）、スピードコントローラ SC3W（`speed-controller.ts`）
  - `src/devices/koganei/` コガネイの電磁弁 F10（`valve.ts`）、シリンダの型式・ロゴ（`cylinder.ts`）
  - `src/devices/smc/` SMC の追加分（`itv.ts`・`blow-valve.ts`・`vacuum-unit.ts`・`slide.ts`）
  - シリンダは SMC と同じ `src/devices/smc/cylinder.ts` の `buildCylinder()` で描く（`maker`・`logo`・`switchMaker`・`speedController` を足した）。
    シリンダスイッチは `src/devices/smc/autoswitch.ts` にメーカー（`SwitchMaker`: `smc` / `ckd` / `koganei`）を足し、CKD T シリーズ・コガネイ ZE シリーズを同じ仕組み
    （パラメータ `switch`・`switchPos`・`lead`、端子 `SW1.BN` など）で付ける
- テスト: `src/devices/air-catalog.test.ts`（型式、シリンダスイッチの端子と定格、電磁弁 → スピコン → シリンダの配管の圧力とエアの指摘、
  マニホールドの装着、PLC の出力 → コイルの極性、電空レギュレータの供給圧力、2 ポート弁の向き、空圧回路図）

## チェック・図面での扱い

- 電磁弁のコイルは DC24V ±10% の受電端子（極性あり。VX21 だけ無極性）で、消費電流を `loadCurrent` に書いた。PLC の出力・リレー接点の定格、電源の容量のチェックに入る
- 電磁弁 → シリンダの配管は、既存のエアのチェック（`src/check/pneumatic.ts`）がそのまま効く（圧力の伝わり、使用圧力範囲、A・B の取り違え、継手のねじ、マニホールドへの装着）
- マニホールド M4GA1 は SMC SS5Y□-41 と同じ `bus` / `mount` の作り。型式の連数・切換えの記号（混在は 8）は装着した連から決まる
- 電空レギュレータは減圧弁の記号で描き、二次側の圧力はパラメータ `outMax`（使う最大の出力圧力）にする。供給は `outMax` + 0.1MPa 以上を求める
- 2 ポート電磁弁は空圧回路図で 2 ポート 2 位置の記号（通電で 1 → 2 が通じ、通電していないと閉じる）を描く（`src/schematic/sheets/pneumatic.ts` の `drawValve` に 2 ポートを足した）
- 部品表のチューブ・ねじのポートの継手（KQ2H）は、メーカーを問わず既存の作り（SMC の型式）で入る

## 簡略化したこと・未対応

- SMC VQ1000 / VQC1000 は、プラグイン形のベースと D サブ・フラットケーブルの一括配線の作りが要るため、今回は入れていない（あとで VQC1000 を足した。下の「空圧の残り」の節）
- SMC 薄形シリンダ CDQ2 は、既存の `smc.cq2`（CQ2 / CDQ2。マグネット内蔵はオートスイッチのパラメータ）で表せるので足していない
- 真空ユニット ZK2 の破壊弁の通り道（SUP → V）は、真空のポートが圧力の計算の対象外のため書いていない。空圧回路図では真空エジェクタを描かない（既存の ZH と同じ）。圧力スイッチ付きの機種は扱わない
- MY1B は空圧回路図で複動シリンダの記号（head = L、rod = R）で描く
- CKD・コガネイのシリンダにはスピードコントローラを直付けするパラメータを出さない（SC3W などを別に置く）。CKD の FRL（C シリーズ）・コガネイのマニホールドは未対応
- メーカーの外観（色・ロゴの位置）、シリンダの外形寸法は近似

## 空圧の残り（#33・#78 の残り）: プラグイン形マニホールド・ISE30A・ソフトスタート弁・M3 のスピコン直付け・KQ2R の記号

### 仕組みの変更

- **プラグイン形（一括配線）のマニホールド**: 親の `bus.host.plugIn`（`PlugInWiringSpec`。コネクタの端子 ID・配線・ソレノイドに割り付けるピンの順・コモンのピン）を足した。
  `src/model/bus.ts` が連の順にピンを割り付け（ダブル配線はどの連も 2 本、配線指定はソレノイドの数）、連の params の `solA` / `solB`（ピン番号）と、親の params の `plugInMap` に入れる。
  ピンが足りなければ `manifold-pins-over` を指摘する。
  ソレノイドのコイルは親のコネクタのピン（受電端子。端子ごとの `loadCurrent`）として書き、COM のピンは弁の数だけの電流を受ける。
  これで PLC の出力 → ケーブル（片側バラ線・変換端子台）→ ピン → COM の極性・電圧、出力の定格、電源の容量のチェックがそのまま効く。弁のコモン（プラス / マイナス）はピンの受電条件で確かめる
- バルブエディタ: プラグイン形のマニホールドでは、連ごとにソレノイドのピン番号と PLC の出力を表示し、出力を選ぶとコネクタにつないだケーブル・変換端子台のそのピンの端子へ電線を引く
  （`src/model/manifold.ts` の `setPlugInOutput`）。COM の配線の有無も出す。インスペクタ・空圧回路図（ソレノイドの横の入出力番号）・I/O 表にもピンを通した出力が出る
- 空圧回路図の記号を 2 つ足した: `soft-start`（ソフトスタート弁。ソレノイド・ばねの 3 ポート 2 位置と二次側の可変絞りを破線でまとめ、ソレノイドの横に PLC の出力を書く。主管の 3 点セットの並びに入る）、
  `reducer`（異径継手。作業ポートの配管の途中に段のついた管と名前・型式を描く。KQ2R をこれにした）
- M3 のポートへのスピードコントローラの直付け: エルボ形に AS1201F-M3（φ3.2・φ4。M3 はガスケットシールで S を付けない）を足し、MHZ2 のサイズ 6・10、MSQ のサイズ 1〜3 にも付くようにした。
  M3 に φ6 の型式はないので、今までどおり付けずに赤い文字を出す。M3 のメータイン（AS1211F-M3）は部品表で推定とする。`threadSize()` が M3 を返すようにした

### 簡略化したこと・未対応

- VQC1000 の弁はマニホールドに装着して使う形だけ。D サブの配線指定（-K）のピンの順は、ダブル配線の並び（1・14・2・15 …）を詰めて使うものとした（推定）
- プラグイン形のマニホールドのソレノイドは、展開図ではコイルの記号にせず、マニホールドのコネクタの箱にまとめる
- 弁のコモンが混在したとき（プラスコモンとマイナスコモンの弁を同じマニホールドに付けたとき）は、多いほうを COM の受電条件にし、少ないほうの弁のピンの極性の誤りとして指摘する
- ISE30A の単位の記号・配管の T1・N7H など、上の表にない形式は扱わない。AV は AV2000 だけ（AV3000〜5000 は未対応）
- CKD の FRL（W1000 など）・コガネイのマニホールドは未対応
