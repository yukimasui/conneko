# モーターと駆動機器の機器定義の一覧

生産設備でよく使うモーターと、その駆動機器（インバーター・サーボアンプ・ステッピングモーターのドライバー）の機器定義の一覧と、
型式の選び方・電気的な表し方・推定の内容・出典をまとめる。
三相誘導電動機（`generic.motor.3p`）と FR-E820-0.75K（`mitsubishi.fr-e820-0.75k`）は以前から収録済みで、FR-E820-0.75K の詳細は [mitsubishi-catalog.md](mitsubishi-catalog.md) を参照。

調査は 2026-10 時点。メーカーのサイトの PDF に直接届かなかったため、メーカーの「仕様から探す」ページ・販売店の仕様表・取扱説明書の抜粋（検索で確かめた範囲）による。
資料で確かめられなかった値は「推定」と書き、機器定義の `estimated` にも書いた。

- 機器定義: `src/devices/catalog/`（1 機器 1 ファイル）
- 共通部品
  - `src/devices/mitsubishi/fr-e800.ts` FR-E820 / FR-E820S の作り（容量ごとの幅・定格電流を渡して作る。FR-E820-0.75K もこれで作る）
  - `src/devices/mitsubishi/melservo.ts` MELSERVO-J5 のサーボアンプとサーボモーターの組み合わせ・定格の表、エンコーダーのコネクタの種類
  - `src/devices/oriental/az.ts` オリエンタルモーター AZ シリーズのモーターの表、モーターのコネクタの種類
- 電気チェックのテスト: `src/devices/drive.test.ts`

## 2. 型式の選び方

- **インバーター**: 三菱電機の小形の汎用インバーターの現行品 FR-E800 の標準品（FM 出力タイプ -1）で、0.1K〜3.7K をそろえた。
  単相 200V 入力の代表として FR-E820S-0.75K-1 を入れた。FR-D720S（FR-D700 シリーズの単相 200V）は販売を終えた機種で、後継の FR-E820S を収録した。
  5.5K 以上・400V 級（FR-E840）・100V 級（FR-E810W）は未収録（`buildFrE800` に容量の値を渡せば作れる）。
- **サーボ**: MELSERVO-J5 のうち、PLC の位置決めユニットからパルス列で動かす汎用インタフェースの MR-J5-□A を選んだ（ネットワーク形の MR-J5-□G は 7 章で追加）。
  サーボモーターは小容量で最もよく使う HK-KT（低慣性）。サーボアンプとサーボモーターは容量で組み合わせる（10A ↔ 13W、20A ↔ 23W、40A ↔ 43W、70A ↔ 7M3W）。
- **ステッピングモーター**: 設備の小さな位置決めに多いオリエンタルモーターの AZ シリーズのうち、盤の DC24V で使える DC 電源入力・位置決め機能内蔵のドライバー AZD-KD。
- **汎用のモーター**: コンベヤ・昇降装置のブレーキモーターと、正逆転させる小形の単相レバーシブルモーター。どちらもメーカーを特定しない汎用品とした。

## 3. 電気的な表現

- **インバーター**: [mitsubishi-catalog.md](mitsubishi-catalog.md) の 3 章の FR-E820-0.75K と同じ。容量ごとに `loadCurrent`（定格入力電流）と U・V・W の `limitCurrent`（定格出力電流）が変わる。
  単相品は R/L1・S/L2 の 2 つが `input`（`distinctGroups: [['R/L1', 'S/L2']]`）。0.1K・0.2K は PR の説明に「ブレーキ抵抗器を接続できない」と書いた。
  幅の広い容量（1.5K 以上）は、操作パネルなどを中央に寄せ、主回路端子の並びを幅に合わせて広げて描く。
- **サーボアンプ MR-J5-A**（category は `load`）:
  - L1・L2・L3 は主回路電源の `input`（AC170〜264V。単相のときは L1・L3 を使うので L2 は任意）、`loadCurrent` は主回路電源の定格電流。
  - L11・L21 は制御回路電源の `input`。端子ごとの消費電流 `loadCurrent: 0.2`（下記）で、主回路と別の小さな保護でもよいことを表す。
  - U・V・W は `supply`（AC200V、R/S/T、`limitCurrent` は出力定格電流）。CN2 はエンコーダーのコネクタ（`kind: 'MR-J5-ENC'`、`required`）でサーボモーターの ENC とつなぐ。
  - CN1 の入力（SON・RES・CR・EM2・LSP・LSN・PC・TL）は `signal: { dir: 'in', kind: 'dc', common: 'DICOM' }`。EM2・LSP・LSN・SON は配線を求める（未接続を指摘する）。
    パルス列 PP・NP はオープンコレクタで使う前提で `common: 'OPC'`。DICOM・DOCOM・OPC はシンク・ソースのどちらにも配線できる共通端子（`input`、+/− 両方）。
  - 出力（ALM・RD・INP・ZSP・TLC）は NPN で、`{ from: 出力, to: 'DOCOM', switch: 'output', ratedCurrent: 0.04 }`。エンコーダーのパルス出力 LA〜LZR は `line-driver`。
  - CN1 は 50 ピンのうち位置制御モードで使う主なピンだけを右の縁に並べた（ラベルにピン番号を付けた）。
- **サーボモーター HK-KT**: U・V・W は `input`（AC170〜240V、R/S/T）、`loadCurrent` は定格電流。電磁ブレーキ付きのときだけ B1・B2（DC21.6〜24V、極性なし）があり、
  端子ごとの消費電流 `loadCurrent` にブレーキのコイルの電流を書いた。
- **ドライバー AZD-KD**: CN1 の +・− は主電源の `input`（DC22.8〜50.4V）、`loadCurrent` はモーター別の入力電流。MB1・MB2 はブレーキのリード線をつなぐ `signal`（ドライバーが制御する）。
  入力 IN0〜IN9 は `dc`（共通 IN-COM[0-7]・IN-COM[8-9]）。出力 OUT0〜OUT5 はパラメータ「出力の配線」でシンク（`npn`）/ ソース（`pnp`）を選び、`to: 'OUT-COM'` の出力（40mA）。
  CN2 はモーターのコネクタ（`kind: 'OM-AZ-MOTOR'`、`required`）。
- **ブレーキ付き三相モーター**: U・V・W は `generic.motor.3p` と同じ。B1・B2 はブレーキ電源の `input`（AC200V: AC180〜220V、DC24V: DC21.6〜26.4V 極性なし）で、
  端子ごとの消費電流（AC 0.1A / DC 0.5A の代表値）。展開図ではモーターとブレーキのコイルを描く（`schematic.elements`）。
- **単相レバーシブルモーター**: COM・CW・CCW は単相（定格の ±10%）の `input`。`distinctGroups: [['COM', 'CW'], ['COM', 'CCW']]`。一方向だけで使うときのため CCW は任意。
  運転用のコンデンサは CW-CCW 間につないだ状態で描き、端子にはしない。

### 端子ごとの消費電流（`TerminalDef.loadCurrent`）

モーターの電磁ブレーキやサーボアンプの制御回路電源のように、機器の主な消費電流（`DeviceDefinition.loadCurrent`）とは別の回路の受電端子には、
端子に `loadCurrent`[A] を書く。チェックでは、その端子から受電する電源の容量（`supply-overload`）・その端子の上流の保護（`overload`）・その端子を開閉する接点や出力の定格に、
機器の `loadCurrent` ではなく端子の値を使う（`src/check/model.ts` の `inputLoads`）。書かなければ今までどおり機器の `loadCurrent` で数える。

## 5. 表せなかったもの・収録しなかったもの

- **サーボアンプの CN1 の全ピン**: アナログ入力（VC・TLA）・P15R・速度 / トルク制御モードの信号などは省いた。中継端子台（MR-TB50）とケーブルは機器にしていない。
- **電磁ブレーキインタロック（MBR）**: MR-J5-A ではパラメータで出力に割り付けるため、端子にしていない（説明に書いた）。
- **STO（安全停止）**: MR-J5-A の CN8、FR-E820 の S1・S2 の 2 チャンネルの安全チェックはしていない。
- **サーボアンプ・ドライバーの出力をモーター以外につなぐ誤り**: サーボアンプの U・V・W は AC200V の電源出力として表したので、サーボモーターを商用電源に直接つないでも電圧の指摘にはならない（説明に「直接つないではいけない」と書いた）。
- **RS-485・USB の通信ポート**（AZD-KD）、**AZ シリーズの AC 電源入力のドライバー**（AZD-A□ など）、**オリエンタルモーターのブラシレスモーター BMU**: 未収録（BLE2 は 7 章で追加）。
- **単相モーターのリード線の色**: メーカーで違うため、端子は役割の名前（COM・CW・CCW）にした。

### 7.2 型式の選び方

- **FR-A820**: 三菱電機の高機能インバーター FR-A800 の標準品から、設備でよく使う 0.75K〜3.7K を選んだ（`buildFrA800` に容量の値を渡せばほかの容量も作れる）。
  定格は初期設定の ND（普通負荷）で表した。0.4K〜7.5K はブレーキ抵抗器を内蔵している（PR-PX 間の短絡片）。
- **ブレーキ抵抗器 MRS**: FR-E800・FR-A800 の小容量に使う 3%ED の MRS 形。高頻度用の FR-ABR 形は未収録。
- **MR-J5-□G**: CC-Link IE TSN でモーションユニット（RD78G など）から動かす形。サーボモーターは MR-J5-A と同じ HK-KT と組み合わせる。
- **GA500**: 安川電機の小形高機能インバーターの三相 200V 級から、0.75kW・2.2kW・3.7kW（重負荷 HD、出荷時の設定）。単相品・400V 級は未収録。
- **Σ-7**: パルス列で動かすアナログ電圧・パルス列指令形のサーボパック SGD7S-□A00A と、よく使う中慣性・高速のサーボモーター SGM7J（100〜750W）。
  MECHATROLINK-III 形（SGD7S-□A20A）・EtherCAT 形は未収録。
- **BLE2**: 設備のコンベヤでよく使うブラシレスモーターの速度制御のセット。ギヤヘッド付き（GFS）・電磁ブレーキ付きは未収録。

### 7.3 電気的な表現

- **FR-A820**: FR-E820（3 章）と同じ考え方。R/L1・S/L2・T/L3 が `input`、U・V・W が `supply`（`limitCurrent` は ND の定格出力電流）、`loadCurrent` は定格入力電流。
  制御回路電源 R1/L11・S1/L21 は任意の `input`（出荷時は短絡片で主回路から受電するが、短絡片は表していない）。
  接点入力 STF〜CS は無電圧接点の入力（`dry`）、RUN・SU・IPF・OL・FU は SE を共通にした NPN 出力、A1-B1-C1・A2-B2-C2 はリレーの a・b 接点。
  異常出力の端子 ID は FR-E820 とそろえて A・B・C（印字は A1・B1・C1）にした。P/+・PR・PX・P1・N/- は `signal`（電源のチェックをしない）。
- **ブレーキ抵抗器 MRS**: リード線 P・PR はどちらも `signal`（インバーターの P/+・PR と同じ扱い。抵抗値と容量の組み合わせのチェックはしない）。
- **MR-J5-G**: 主回路・制御回路電源・U・V・W・CN2 は MR-J5-A と同じ。CN1A・CN1B は RJ-45 で `protocols: ['cc-link-ie-tsn']`（一般の Ethernet の機器とつなぐと `protocol-mismatch`。テストあり）。
  CN3 の EM2・LSP・LSN・DOG は DICOM を共通にした DC 入力（EM2・LSP・LSN は配線を求める）、MBR・INP・ALM は DOCOM を共通にした NPN 出力（40mA）。
- **GA500**: FR-A820 と同じ考え方。S1〜S7 は `dry`、SP（+24V）・SN（0V）は内部電源の `supply`、MA-MC・MB-MC はリレー接点、P1-C1・P2-C2 は組ごとのフォトカプラ出力、
  A1（電圧）・A2（電流）は AC を基準にしたアナログ入力。モーター側の端子は ID を U・V・W、印字を U/T1・V/T2・W/T3 にした。
- **SGD7S**: L1・L2・L3 が主回路の `input`（単相で使うときのため L3 は任意）、L1C・L2C が制御電源の `input`（端子ごとの消費電流 0.2A）。
  CN1 の入力は +24VIN を共通にした DC 入力、/PULS・/SIGN はオープンコレクタで使う前提で PL1・PL2 を共通にした。ALM・/COIN・/S-RDY は + と − の組のフォトカプラ出力。
  CN2 はエンコーダーのコネクタ（`kind: 'YASKAWA-SIGMA7-ENC'`、`required`）で、三菱電機のサーボモーターとは合わない（テストあり）。
- **SGM7J**: HK-KT と同じ考え方。保持ブレーキ付きのときだけ B1・B2（DC24V ±10%、極性なし）があり、端子ごとの消費電流にブレーキの電流を書いた。
- **BLE2D**: 主電源は -A が L・N（端子 ID は L1・L2）、-C の単相が L1・L2、三相が L1・L2・L3。`loadCurrent` は容量と電源ごとの定格入力電流。
  IN0〜IN6 は IN-COM を共通にした DC 入力、OUT0・OUT1 は OUT-COM を共通にした NPN 出力、VM は VL を基準にしたアナログ電圧入力。
  CN2 はモーターのコネクタ（`kind: 'OM-BLE2-MOTOR'`、`required`）で、AZ シリーズのモーターとは合わない。
- **始動電流（`inrush`）**: どの機器もインバーター・ドライバーで駆動するため書いていない（直入れのモーターではない）。

### 7.5 表せなかったもの・収録しなかったもの

- **FR-A820 の短絡片**: R1/L11-R/L1・S1/L21-S/L2、P1-P/+、PR-PX の短絡片は絵だけで、内部経路にしていない（制御回路電源を別にする・外付けのブレーキ抵抗器にする配線の誤りは指摘しない）。
- **ブレーキ抵抗器の選定**: 抵抗値がインバーターの最小抵抗値を下回る組み合わせ・FR-E820 の 0.1K・0.2K（ブレーキトランジスタなし）につなぐ誤りはチェックしない。
- **GA500・SGD7S のシンク / ソースの切換え**: 出荷時の設定（シンク・内部電源）だけを表した。
- **BLE2 の電磁ブレーキ・ギヤヘッド・RS-485 通信**: 未収録。
- **MR-J5-G のモーションユニット（RD78G）**: 未収録（CN1A に CC-Link IE TSN の機器をつなぐと通信方式のチェックが効く）。
- **STO（安全停止）**: MR-J5-G の CN8、GA500 の H1・H2、SGD7S の CN8 の 2 チャンネルの安全チェックはしていない。
